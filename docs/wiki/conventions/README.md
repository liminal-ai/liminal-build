# Conventions

This section collects the universal cross-system rules of the codebase: shared vocabulary, repository layout, coding patterns, verification expectations, and the error-code catalog.

## Boundary

Conventions are the rules that hold across subsystems. Subsystem mechanics — how the archive finalization service is shaped, how source resolution composes, how a specific Convex table is indexed — live on the relevant page in [Current Technical Design](../current-technical-design/README.md). If a rule applies everywhere, it belongs here. If it explains how one subsystem works, it belongs there.
